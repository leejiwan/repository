## 4. 이슈 및 주요 결정 사항
- **프레임워크 배제**: 외부 프레임워크 없이 순수 자바스크립트(Vanilla JS)로 구현하여 최고의 로딩 속도와 호환성 확보.
- **클라이언트 전용 아키텍처**: 별도의 서버/DB 없이 `localStorage` 기반 단일 페이지 웹 앱(SPA)으로 설계.
- **카테고리 확장**: 업무(work), 개인(personal), 공부(study) 3대 카테고리로 확장하고 전용 시각 테마 컬러 부여.
- **UX 및 접근성 극대화**: 실시간 진행률 대시보드, 다크 모드, 키보드 단축키(Alt+N, Alt+1~4), 드래그 앤 드롭을 통한 사용자 인터랙션 강화.
- **데이터 안정성**: 브라우저 로컬 저장소 외에 JSON 파일 내보내기/가져오기 기능을 도입하여 기기 간 데이터 백업/이전 지원.
- **반응형 디자인 고도화**: 데스크톱 대화면부터 320px 소형 모바일 기기까지 레이아웃 깨짐 없이 직관적으로 동작하도록 반응형 브레이크포인트와 터치 친화적 인터랙션 구축.
